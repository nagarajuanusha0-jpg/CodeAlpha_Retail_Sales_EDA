
# Retail Sales Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to understand sales performance, profitability, product categories, and regional trends.

## Objectives
- Explore and understand the retail dataset.
- Identify missing and duplicate records.
- Perform statistical analysis.
- Analyse category-wise and region-wise sales.
- Identify profitable and loss-making sub-categories.
- Visualize important business insights.

## Dataset
The project uses the Superstore retail sales dataset.

The dataset contains information about:
- Ship Mode
- Customer Segment
- Country and City
- Region
- Product Category
- Product Sub-Category
- Sales
- Quantity
- Discount
- Profit

## Technologies Used
- Python
- Pandas
- Matplotlib
- VS Code

## Analysis Performed
1. Dataset exploration
2. Missing value detection
3. Duplicate record removal
4. Statistical analysis
5. Category-wise sales and profit analysis
6. Region-wise sales analysis
7. Sub-category analysis
8. Loss-making product identification
9. Data visualization

## Key Findings
- Technology generates the highest sales.
- Technology generates the highest category-wise profit.
- West is the highest sales region.
- Phones generate the highest sub-category sales.
- Copiers generate the highest sub-category profit.
- Bookcases, Supplies, and Tables have negative total profit.

## Visualizations
The project generates four charts:

1. Category-wise Sales Analysis
2. Category-wise Profit Analysis
3. Region-wise Sales Analysis
4. Sales Distribution Histogram

## How to Run the Project

1. Install Python.
2. Install required libraries:

   pip install pandas matplotlib

3. Keep eda_analysis.py and superstore.csv in the same folder.
4. Run the following command:

   python eda_analysis.py

## Project Output
The program displays the analysis results in the terminal and generates four visualization images.
